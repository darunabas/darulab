phyloregion: R package for biogeographic regionalization and macroecology

phyloregion is our lab's R package for analysing species distributions at large scales. It includes tools for biogeographic regionalization (taxonomic, phylogenetic and functional), beta diversity, phylogenetic diversity and endemism, conservation prioritization and mapping. It is fast and memory-efficient, so it handles community matrices with many thousands of species and grid cells.

Install

From CRAN:

install.packages("phyloregion")
library(phyloregion)
